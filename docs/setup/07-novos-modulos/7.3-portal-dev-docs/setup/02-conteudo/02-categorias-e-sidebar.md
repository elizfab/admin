# Passo 02 — Categorias e sidebar

> **Fase:** 02 — Conteúdo\
> **Tempo estimado:** 15 min\
> **Depende de:** [Passo 01](01-nova-pagina.md)

## Objetivo

Criar uma categoria nova e controlar a ordem e os rótulos da sidebar.

## 💡 A sidebar é gerada pelas pastas

A sidebar **não** é escrita à mão: o `sidebars.ts` pede ao Docusaurus que a
gere a partir das pastas de `frontend/docs/`. 💡 É como o índice de um
fichário: cada divisória (pasta) vira um capítulo, e a etiqueta da divisória é
o `_category_.json`.

`frontend/sidebars.ts`:

```ts
import type {SidebarsConfig} from '@docusaurus/plugin-content-docs';

// This runs in Node.js - Don't use client-side code here (browser APIs, JSX...)

// A sidebar é gerada a partir da estrutura de pastas em `docs/`.
// Ordem e rótulos: `sidebar_position` no front matter e `_category_.json` em cada pasta.
const sidebars: SidebarsConfig = {
  docsSidebar: [{type: 'autogenerated', dirName: '.'}],
};

export default sidebars;
```

| Arquivo da pasta | Papel |
|---|---|
| `_category_.json` | Rótulo (`label`), ordem (`position`) e se começa fechada (`collapsed`) |
| `index.mdx` | Página que abre ao clicar na categoria; mostra os cards com `<DocCardList />` |

💡 A ordem aceita decimais: a categoria Release usa `"position": 5.5` para
ficar entre a 5 e a 6 sem renumerar as outras.

## Pré-requisitos

- Passo 01 concluído.

## Passo a passo

### 1. Criar a pasta da categoria

```bash
mkdir -p frontend/docs/seguranca
```

`frontend/docs/seguranca/_category_.json`:

```json
{
  "label": "Segurança",
  "position": 7,
  "collapsed": true
}
```

`frontend/docs/seguranca/index.mdx`:

```mdx
---
title: "Segurança"
description: "OWASP, autenticação, segredos e boas práticas."
---

<TechIcon icon="devicon/devicon-original" alt="Segurança" />

OWASP, autenticação, segredos e boas práticas.

<DocCardList />
```

### 2. Colocar a categoria nos menus

A sidebar se atualiza sozinha. O menu **Categorias** da navbar, o rodapé e os
cards da home são **listas fixas**: acrescente a categoria em
`docusaurus.config.ts` (`navbar.items` → dropdown e `footer.links`) e em
`src/components/CategoryGrid/index.tsx` (fase 03).

💡 No Admin, a página `/documentation` lista as categorias **sozinha**: ela lê
o `portal-build.json`, gerado a partir dos `_category_.json` (fase 04).

## Arquivos criados ou alterados

| Arquivo | Ação | Descrição |
|---|---|---|
| `frontend/docs/<categoria>/_category_.json` | Criado | Rótulo e posição |
| `frontend/docs/<categoria>/index.mdx` | Criado | Página da categoria |
| `frontend/docusaurus.config.ts` | Alterado | Menu e rodapé |
| `frontend/src/components/CategoryGrid/index.tsx` | Alterado | Card na home |

## ✅ Como testar

| # | Teste | Resultado esperado |
|---|---|---|
| 1 | `npm start` | A categoria aparece na sidebar, na posição definida |
| 2 | Clicar na categoria | Abre o `index.mdx` com os cards das páginas |
| 3 | `npm run build` | Sem erros |

**Critério de aceite:** os 3 testes passam.

## ⚠️ Problemas comuns

| Sintoma | Causa provável | Solução |
|---|---|---|
| Categoria com o nome da pasta | `_category_.json` com erro de JSON | Valide o JSON (vírgula sobrando é o erro mais comum) |
| Categoria sem página própria | Falta o `index.mdx` | Crie o `index.mdx` com `<DocCardList />` |

## Commit sugerido

```bash
git add frontend/docs/<categoria> frontend/docusaurus.config.ts frontend/src/components/CategoryGrid
git commit -m "docs: adiciona categoria <categoria>"
```
